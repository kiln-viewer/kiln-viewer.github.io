窯の火を絶やさずに

Kiln は無料・オープンソースであり、これからも変わりません。スポンサー資金はビルドマシン、コード署名、新しいクリエイターツールに充てます。受付開始までは、フォローが何よりの支援です。

GitHub でフォロー

4 つの支援方法（最初のプレビューと同時に開始）

GitHub Sponsors

毎月または一回きり、GitHub アカウントから直接。すでに GitHub で Kiln をフォローしている方に最適です。

Ko-fi

カードまたは PayPal で一回きりのチップ。アカウント不要です。

Open Collective

すべての支出が公開されるので、資金の使い道を正確に確認できます。

Second Life でチップ

インワールドの Kiln チップジャーに、ビルダーへのチップと同じ感覚でリンデンドルを送れます。

その他の協力方法

バグを報告

Kiln で不具合がありましたか？何が起きたかを、できればログを添えてお知らせください。

ツールを提案

何を作っていて、どこで手間取っているかを教えてください。

GitHub でフォロー

作業の様子をリアルタイムで追い、最初のプレビュー公開時にお知らせを受け取れます。
