Halt den Ofen heiß

Kiln ist kostenlos und Open Source, und das bleibt so. Unterstützung bezahlt Build-Rechner, Code-Signierung und neue Werkzeuge für Creator. Ko-fi und Trinkgeld in Second Life gehen schon jetzt; GitHub Sponsors und Open Collective öffnen mit der ersten Preview.

Auf GitHub folgen

Vier Wege zu geben

GitHub Sponsors

Monatlich oder einmalig, direkt über dein GitHub-Konto. Ideal, wenn du Kiln dort schon folgst.

Ko-fi

Ein einmaliges Trinkgeld per Karte oder PayPal, ganz ohne Konto.

Auf Ko-fi geben

Open Collective

Jede Ausgabe ist öffentlich, so siehst du genau, wohin das Geld fließt.

Trinkgeld in Second Life

Schick kilnviewer Resident in-world Linden-Dollar, so wie du einem Builder Trinkgeld gibst: Profil öffnen und Bezahlen wählen.
