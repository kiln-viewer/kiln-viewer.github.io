가마의 불을 지켜 주세요

Kiln은 무료 오픈소스이며 앞으로도 그렇습니다. 후원금은 빌드 서버, 코드 서명, 크리에이터를 위한 새 도구에 쓰입니다. Second Life 인월드 팁은 지금 바로 보낼 수 있고, 나머지 세 가지는 첫 프리뷰와 함께 열립니다.

GitHub에서 팔로우

네 가지 후원 방법

GitHub Sponsors

GitHub 계정에서 바로 매월 또는 일회 후원. 이미 GitHub에서 Kiln을 팔로우하고 있다면 가장 편합니다.

Ko-fi

카드나 PayPal로 한 번 팁을 보냅니다. 계정이 필요 없습니다.

Open Collective

모든 지출이 공개되므로 돈이 어디에 쓰이는지 정확히 볼 수 있습니다.

세컨드 라이프에서 팁 보내기

인월드에서 kilnviewer Resident에게 린든 달러를 보내 주세요. 프로필을 열고 지불을 누르면 됩니다.
