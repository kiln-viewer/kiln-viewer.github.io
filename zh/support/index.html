讓窯火不熄

Kiln 免費且開放原始碼，未來也會如此。贊助將用於建置主機、程式碼簽章與新的創作者工具。Ko-fi 與 Second Life 內的打賞現在就能使用；GitHub Sponsors 與 Open Collective 將隨第一個預覽版開放。

在 GitHub 上追蹤

四種贊助方式

GitHub Sponsors

每月或單次，直接從你的 GitHub 帳號贊助。若你已在 GitHub 上追蹤 Kiln，這是最方便的方式。

Ko-fi

以信用卡或 PayPal 單次打賞，不需帳號。

在 Ko-fi 贊助

Open Collective

每筆支出都公開，你可以清楚看到錢花在哪裡。

在 Second Life 中打賞

在世界中付林登幣給 kilnviewer Resident，就像打賞建造者一樣：開啟個人檔案並選擇「付款」。

在 Second Life 中開啟 在網頁上查看個人檔案

其他幫忙方式

回報錯誤

Kiln 出了問題嗎？告訴我們發生了什麼，可以的話請附上記錄檔。

建議工具

說說你在做什麼，以及什麼拖慢了你。

在 GitHub 上追蹤

即時關注進度，並在第一個預覽版推出時收到通知。
